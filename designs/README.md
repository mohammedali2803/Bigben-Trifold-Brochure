# Bigben print designs

Print artwork (prints only, no garment mock-ups) for six collections of six colourways each.

| # | Collection | Print type | Refs |
|---|---|---|---|
| C1 | Type Lab | 2-colour screen print | TL-01 – TL-06 |
| C2 | Sticker Club | 4-colour screen print | SC-01 – SC-06 |
| C3 | Hyper Real | Photo / digital print (DTF) | HR-01 – HR-06 |
| C4 | Weekend Club | Front + back print | WC-01 – WC-06 |
| C5 | Crest & Co. | Small chest + large back print | CR-01 – CR-06 |
| C6 | Repeat Room | All-over print (seamless repeat) | RR-01 – RR-06 |

## Where the images are

`output/collections/<collection>/`
- `<collection>-overview.png`: one-page overview of the collection
- `prints/<ref>-<name>[-front|-back|-chest|-tile].png`: production artwork, 3000 px wide, transparent background
- `prints/*-preview.png`: the same artwork on its garment colour, for easy viewing (repeat tiles show a 3 × 3 repeat)

`output/bigben-print-collections.zip` contains everything above.

## Rebuilding

```
npm install
node render-3d.mjs            # 3D / procedural imagery for C3 → output/assets/3d
node build-collections.mjs    # all collections (or pass ids, e.g. c1-type-lab)
```

- `collections/*.mjs` — one file per collection: artwork, garment colours, inks
- `lib/` — rendering (Playwright) and SVG helpers (halftone, stars, arcs, pixel art)
- `3d/` — three.js scenes for the photo-print collection
- `fonts/` — SIL Open Font License fonts from Google Fonts (`fonts/fetch-fonts.sh`); free for commercial use, including on garments

## Rights

Every motif is drawn here from scratch. There are no images from the web, no stock photos and no licensed characters. The 3D renders in C3 are generated by `3d/scenes.js`.

## Status

These are **design proposals for approval, not production files**:
- Refs like `TL-01` are proposal numbers, not style numbers.
- Garment and ink colours on screen are approximate; match them to fabric swatches and Pantone references with the printer.
- Ink counts exclude any white underbase the printer may need on dark garments.
- Before screens or DTF films are made, print sizes per size range must be set, and the artwork exported as separated vector or film files.

`build.mjs`, `src/` and `sheets/` hold the earlier T-shirt flat sheet (P01), kept for reference.
